# Koneva Legal — сайт, этап 1 (визуальная версия)

## Как запустить
Нужен только браузер, ничего устанавливать не надо.
- Быстро: откройте `index.html` двойным щелчком. (Если окна с делами/направлениями не открываются по прямым ссылкам — запустите локальный сервер.)
- Локальный сервер: в папке сайта выполните `python3 -m http.server 8000` и откройте http://localhost:8000
- Публикация: загрузите папку целиком на любой статический хостинг.

## Что редактировать (папка data/)
- `site.config.js` — имя, опыт, контакты, соцсети, домен
- `cases.js` — судебные дела (как добавить — инструкция в начале файла)
- `practice.js` — тексты направлений
- `services.js` — услуги и цены (режимы: индивидуально / фикс / диапазон)
- Фото: `assets/img/portrait.jpg` и `assets/img/work.jpg`

## Заготовки, которые нужно заполнить
Помечены на сайте как «[… — заполнить]»: e-mail, Telegram, телефон, соцсети, город, часы работы, образование, статус, регион.

## Форма
Демонстрационная: ничего не отправляет и не сохраняет. Защита от отправки также задана в CSP в <head> каждой страницы.
